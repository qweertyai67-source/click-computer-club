# КЛИК — сайт компьютерного клуба

Адаптивный сайт-концепт компьютерного клуба «КЛИК» в Краснодаре. Проект собран на React 19, TypeScript и Vite 6 на основе прежнего макета, но с отдельной структурой, новым брендингом и фотографиями клуба.

## Что реализовано

- сине-бирюзовая визуальная система по фотографиям интерьера;
- зоны Standard, VIP на двоих и Boot-Camp;
- интерактивный демонстрационный выбор даты, времени, зоны и места;
- тарифы, перенесённые с предоставленной фотографии меню;
- галерея реальных фотографий клуба с полноэкранным просмотром;
- контакты, маршрут через 2ГИС, телефон, Telegram и WhatsApp;
- адаптивные версии для мобильных, планшетов и широких экранов;
- клавиатурная навигация, focus-состояния и reduced-motion.

## Запуск

```powershell
pnpm install
pnpm dev
```

Проверки:

```powershell
pnpm typecheck
pnpm lint
pnpm build
```

Основные данные клуба находятся в `src/club.config.ts`, зоны и тарифы — в `src/data.ts`, стили — в `src/styles.css`, фотографии — в `public/photos`.
